# LifeTime – India's Financial Exchange (Landing Page)

Landing page built with HTML, CSS and jQuery, served with Python (Flask).

## Structure
```
app.py
requirements.txt
site/
  index.html
  style.css
  script.js
  images/
```

## Run with Python
```
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000 in your browser.

## Run without Python
Open `site/index.html` directly in a browser.

## Features
- Responsive layout (desktop, tablet, mobile)
- Early-access waitlist form with jQuery validation
